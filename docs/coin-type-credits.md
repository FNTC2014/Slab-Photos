# Coin type references: photo credits

Slab Plates turns coins upright by matching them against upright photos of each Canadian coin type from 1858 to 1967 (`src/coinrefs.js`). The app holds only a reduced map of each design's edges, not the photos. The maps were made from these freely licensed photos on Wikimedia Commons, and from the app owner's own 1967 dollar.
